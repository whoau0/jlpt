# 🌟 키라키라 (Kirakira / キラキラ)
### AI 실시간 일본어 프리토킹 전화 튜터 (JLPT N4 대비)

애니메이션으로 일본어 귀는 트였지만 실제 회화 경험이 적은 초급 학습자를 위한 **8분 실시간 음성 통화 시뮬레이터**입니다.

---

## 💡 주요 특징

1. **실제 전화 같은 실시간 음성 대화 (Low Latency)**
   - Google의 최신 양방향 스트리밍 모델인 **`gemini-3.8-live`**를 적용하여, 내가 말하면 딜레이 없이 자연스럽게 대답합니다.
2. **대화 흐름을 깨지 않는 친구 페르소나**
   - 통화 중에는 문법이나 조사를 사사건건 지적하지 않고, 친구처럼 풍부한 맞장구(相槌)로 말문을 열어줍니다.
3. **한국어 SOS 지원 모드**
   - 못 알아듣는 일본어가 나왔을 때 당황하지 않고 **"무슨 뜻이야?"**, **"한국어로 설명해 줘"**라고 하거나 한국어로 말하면, 키라키라가 즉시 한국어로 뜻을 풀어서 설명해주고 N4 수준의 쉬운 일본어 답변 예시를 알려줍니다.
4. **8분 점진적 난이도 심화 (N5 $\rightarrow$ N4)**
   - **Step 1 (0:00~1:30)**: 일상 및 취미 (애니메이션, 음식, 가벼운 대화)
   - **Step 2 (1:30~3:00)**: 내 일과 공부 (하루 일과, 루틴)
   - **Step 3 (3:00~5:00)**: 지난 경험과 에피소드 (과거형 `〜たことがある`, 여행 이야기)
   - **Step 4 (5:00~6:30)**: 의견과 선택 (이유 표현 `〜から`, 생각 `〜と思う`)
   - **Step 5 (6:30~8:00)**: 가정 상황 (가정법 `〜たら`, `もし〜`)
5. **통화 후 자동 복습 리포트 생성**
   - 통화가 끝나면 `logs/` 폴더에 **대화 전문(TXT, JSON)**과 함께 **JLPT N4 맞춤형 복습 피드백 리포트(MD)**가 자동 생성됩니다.
   - 학생이 말했던 어색한 표현을 더 자연스러운 원어민 표현으로 바꾼 `Before & After`, 오늘 대화의 핵심 단어/문형 정리 제공!

## 🚀 빠른 시작 (모니터 화면에서 바로 보기!)

터미널을 다룰 줄 몰라도 괜찮습니다! **더블클릭 한 번으로 모니터에 스마트폰 통화 화면**이 열립니다.

1. **실행하기**:
   * 폴더 안의 **`run.bat`** 파일을 더블클릭합니다.
   * 자동으로 크롬/엣지 웹 브라우저가 열리며 헤이링 스타일의 스마트폰 통화 화면이 모니터에 뜹니다!
   * (주소: `http://localhost:8000`)
2. **통화하기**:
   * 화면 가운데 아래의 초록색 **[통화 시작]** 버튼을 누릅니다.
   * 브라우저에서 '마이크 사용 허용'을 누르면 키라키라가 먼저 반갑게 말을 걸어옵니다.
   * 화면에서 실시간 자막, 남은 시간, 현재 난이도 단계를 보면서 편하게 이야기하세요.
3. **못 알아들을 땐?**:
   * 화면의 빨간색 **[🆘 방금 무슨 뜻이야?]** 버튼을 누르거나, 마이크로 *"한국어로 설명해줘"*라고 말하세요.
4. **통화 후 복습 리포트**:
   * 빨간색 **[통화 종료]** 버튼을 누르거나 8분이 지나면, 화면이 자동으로 **[🌸 통화 복습 리포트]**로 전환되어 오늘의 교정 표현과 단어/문법을 한눈에 볼 수 있습니다.

---

## 📁 저장되는 기록 파일 (`logs/`)

통화가 종료되면 날짜/시간별로 3종류의 파일이 자동 생성됩니다:
1. `conversation_YYYYMMDD_HHMMSS.txt`: 단계별 발화 타임라인 텍스트
2. `conversation_YYYYMMDD_HHMMSS.json`: 원본 발화 메타데이터 (JSON)
3. `feedback_YYYYMMDD_HHMMSS.md`: 키라키라의 편지, Before & After 교정, 핵심 어휘/문형이 담긴 복습 리포트

---

## 🛠️ 기술 스택
* **Language**: Python 3.11
* **Live Engine**: Google Gemini Multimodal Live API (`gemini-3.8-live`)
* **Feedback Engine**: Google Gemini Flash Lite (`gemini-3.5-flash-lite`)
* **Audio I/O**: PyAudio (16kHz PCM Mic Input / 24kHz PCM Speaker Output)
* **SDK**: `google-genai` (Official Latest SDK)
